# XXL set 0.1

Four free plugins for Akai Force / MPC OS (ARMv7), all in this one release.

| Download | What it is |
|---|---|
| `XXL-STRIP-0.1.1-mpc-armv7.zip` | **XXL STRIP**: an emulation of a classic large-format British console channel strip (4000 E / G style): drive, filters, four-band EQ in three models, compressor, gate / expander, VU meter. |
| `XXL-STRIP-BUS-0.1.1-mpc-armv7.zip` | **XXL STRIP BUS**: an emulation of the classic console stereo bus compressor (G-series style), with a VU meter. |
| `XXL-STRIP-MASTER-0.1.1-mpc-armv7.zip` | **XXL STRIP MASTER**: master-bus strip in the same console style: drive, shelving EQ, high-frequency compressor, stereo image, transformer stage. |
| `XXL-Pro-0.1.0-mpc-armv7.zip` | **XXL Pro**: fifteen emulations of classic studio processors on a patch bay (list below). |

**XXL Pro** ("Pro" is for Process) is fifteen emulations of classic studio processors in one plugin, joined on a patch bay: patch any module into any other and into the output, in series or in parallel.

| Module | Emulation of |
|---|---|
| XXL-2A | LA-2A-style optical tube levelling amplifier |
| XXL-1B | CL 1B-style optical tube compressor |
| XXL-16VU | 160 VU-style VCA compressor / limiter |
| XXL-76 | 1176-style FET limiting amplifier |
| XXL-67 | 670-style stereo vari-mu tube limiter |
| XXL-DISS | Distressor-style character compressor |
| XXL-73 | 1073-style preamp and EQ |
| XXL-55A | 550A-style 3-band proportional-Q EQ |
| XXL-56 | 560-style 10-band graphic EQ |
| XXL-EQ1-A | EQP-1A-style passive program equalizer |
| XXL-MQ-5 | MEQ-5-style passive mid-range equalizer |
| XXL-A80 | A80-style multitrack tape machine |
| XXL-AT12 | ATR-102-style mastering tape recorder |
| XXL-224 | 224-style digital reverb |
| XXL-480R | 480L-style digital reverb |

Unzip the one you want and run `install.sh` on the device; `uninstall.sh` removes it. Free.

Tested and running on an Akai Force (L'Cronx, 2026-11-14).
SHA-256 sums: `SHA256SUMS.txt` in this release.
